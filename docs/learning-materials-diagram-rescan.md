## 优先修复规则

1. 流程图：不要把箭头做成独立卡片；使用步骤网格、链路卡片或时间线，窄屏按 2 列/1 列重排。
2. 对比图：不要把左右两列文本混在同一张卡片；使用双栏 compare/pair 结构，明确“问题/方案”“危险/安全”“默认/自定义”。
3. 决策树：不要保留“是/否/报错”等散碎卡片；使用分支卡片表达条件、结果和建议。
4. 拓扑图：不要把节点名、IP、端口散落；使用服务卡片、网络分组、调用链表达关系。
5. 知识路线图：不要把方向、阶段、资源混成一堆；使用分栏方向 + 阶段路线 + 推荐资源。
