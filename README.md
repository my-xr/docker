## 二、课程定位与设计理念

### 2.1 课程定位

本课程教授 **Docker 容器技术**与 **Kubernetes 容器编排技术**，帮助学生从"会开发应用"跃迁到"能容器化部署与运维应用"，掌握云原生时代的基础设施技能。

课程分两半：前半部分（24 学时）掌握 Docker 容器化技术，后半部分（24 学时）掌握 Kubernetes 集群编排技术。两部分紧密衔接，形成"容器化 → 编排部署"的完整能力链。

**课程主线**：

```
Docker 部分：容器认知 → 镜像管理 → 容器运行 → Dockerfile 构建 → 网络存储 → Compose 编排
K8s 部分：  集群认知 → 集群搭建 → Pod 管理 → 工作负载 → Service 网络 → 配置存储 → 综合部署
```

### 2.2 六大设计理念

| 序号 | 理念 | 落地方式 |
| --- | --- | --- |
| 1 | PBL 项目化教学导向 | 以"多服务容器化部署项目"贯穿全程 |
| 2 | 产教融合导向 | 内容贴近云原生运维岗位能力要求 |
| 3 | 理论实践结合 | 每模块配套实践任务，6 次实践课 |
| 4 | 能力递进设计 | Docker 基础 → Docker 进阶 → K8s 基础 → K8s 进阶 → 综合实践 |
| 5 | 就业能力导向 | 结合 DevOps/云运维岗位常见工作任务和面试考点 |
| 6 | 课程思政自然融入 | 自主可控基础设施、工程规范、安全意识 |

### 2.3 能力递进路径

```
Docker：容器认知 → 镜像与容器操作 → Dockerfile 构建 → 网络与存储 → Compose 编排
K8s：  集群认知 → 集群搭建 → Pod 与工作负载 → Service 网络 → 配置与存储 → 综合部署运维
```

## 三、课程目标

### 3.1 知识目标

1. 理解容器化思想与 Docker 架构原理。
2. 掌握 Docker 镜像管理（拉取/查看/删除/构建）与容器管理（运行/停止/日志/端口映射）。
3. 掌握 Dockerfile 编写（FROM/RUN/COPY/ADD/WORKDIR/ENV/CMD/ENTRYPOINT/多阶段构建）。
4. 掌握 Docker 网络与数据卷持久化。
5. 掌握 Docker Compose 多容器编排。
6. 理解 Kubernetes 架构（Master/Node/control plane/etcd）。
7. 掌握 K8s 集群搭建（Minikube / kubeadm）。
8. 掌握 Pod、Deployment、Service、ConfigMap、Secret、PV/PVC 等核心资源。
9. 掌握 kubectl 命令操作与 YAML 清单编写。
10. 掌握应用容器化部署到 K8s 集群的完整流程。

### 3.2 能力目标

1. 能够安装配置 Docker 环境并完成镜像与容器操作。
2. 能够编写 Dockerfile 构建应用镜像。
3. 能够使用 Docker Compose 编排多容器应用。
4. 能够搭建 K8s 集群（单机/多节点）。
5. 能够编写 K8s YAML 部署应用（Deployment/Service/ConfigMap/Secret/存储）。
6. 能够使用 kubectl 管理集群资源与排查问题。
7. 能够完成一个多服务应用的容器化部署到 K8s 的完整流程。

### 3.3 素质目标（课程思政）

1. 树立自主可控意识——容器与 K8s 是云原生基础设施，理解国产化替代的意义。
2. 培养工程规范意识——Dockerfile 与 K8s YAML 的规范性。
3. 培养安全意识——镜像安全、Secret 管理、网络隔离。
4. 培养运维责任意识——容器化部署关乎系统稳定。
5. 培养系统思维——从单机到集群、从开发到运维的全局视角。

## 五、贯穿课程项目设计

### 5.1 项目名称

**多服务容器化部署项目**

### 5.2 项目选型理由

1. **场景真实**：企业应用普遍采用容器化部署，贴合实际运维场景。
2. **前后呼应**：可将 JavaWeb 课程的 CTTS 后端 + Vue3 课程的 CTTS-Frontend + MySQL 多服务容器化，与其它课程联动。
3. **分阶段递进**：Docker 部分完成容器化与 Compose 编排，K8s 部分完成集群部署与运维，自然衔接。
4. **覆盖全面**：涉及 Dockerfile、网络、存储、Compose、K8s Deployment/Service/ConfigMap/Secret/Ingress 等核心技术。

### 5.3 项目架构

```
CTTS 多服务架构：
┌──────────┐     ┌──────────┐     ┌──────────┐
│ Frontend │────▶│ Backend  │────▶│  MySQL   │
│ (Vue3)   │     │(SpringBoot)│   │          │
└──────────┘     └──────────┘     └──────────┘
容器化部署：
- Frontend → Docker 镜像 → Nginx 静态服务
- Backend  → Docker 镜像 → Java 运行
- MySQL    → 官方镜像 → 数据卷持久化
K8s 部署：
- 3 个 Deployment + 3 个 Service + ConfigMap + Secret + PV/PVC + Ingress
```

### 5.4 项目八阶段构建

| 阶段 | 对应模块 | 阶段成果 |
| --- | --- | --- |
| 阶段 1 | M1 | 安装 Docker，运行首个容器 |
| 阶段 2 | M2 | 拉取 MySQL/Java/Nginx 镜像，运行容器 |
| 阶段 3 | M3 | 编写 Dockerfile 构建前后端镜像 |
| 阶段 4 | M4 | Compose 编排三服务 + 网络与存储 |
| 阶段 5 | M5 | 搭建 K8s 集群 |
| 阶段 6 | M6 | 部署 Pod 与 Deployment |
| 阶段 7 | M7 | 配置 Service 与 Ingress 对外访问 |
| 阶段 8 | M8 | 配置 ConfigMap/Secret/存储，完成集群部署 |

## 七、48 学时课程进度总览（24 次课）

### Docker 部分（第 1-12 次课）

#### 模块 1：Docker 认知与环境搭建

**第 1 次课（理论）— Docker 认知与容器化思想**
- **主题**：容器化思想；Docker 简介；Docker vs 虚拟机；Docker 架构；云原生概览
- **知识点**：容器vs虚拟机对比、Docker 引擎架构（Client/Server/守护进程）、镜像与容器概念、Docker Hub、云原生生态
- **项目任务**：了解 CTTS 多服务容器化部署目标
- **互动**：课前讨论"开发环境一致性问题——在我电脑上能跑"
- **思政**：自主可控——云原生基础设施的国产化
- **考核点**：容器vs虚拟机、Docker 架构

**第 2 次课（理论）— Docker 安装与初体验**
- **主题**：Linux 环境准备；Docker 安装；镜像加速；首个容器
- **知识点**：Ubuntu 环境准备、Docker 安装（apt/yum）、Docker 服务管理、镜像加速器配置、`docker run hello-world`、`docker version`/`docker info`
- **项目任务**：安装 Docker，运行首个容器
- **互动**：实操演示——学生同步安装 Docker
- **思政**：工程规范——环境标准化是协作基础
- **考核点**：Docker 安装、镜像加速配置、基本命令

#### 模块 2：镜像与容器管理

**第 3 次课（理论）— 镜像管理**
- **主题**：镜像概念；镜像拉取与查看；镜像分层结构；镜像删除与清理
- **知识点**：`docker pull`/`docker images`/`docker image ls`/`docker image rm`、镜像分层（Layer/UnionFS）、`docker image inspect`、`docker image prune`、镜像标签
- **项目任务**：拉取 MySQL/Nginx/OpenJDK 镜像
- **互动**：代码阅读——`docker inspect` 分析镜像分层
- **思政**：资源管理——及时清理无用镜像
- **考核点**：镜像命令、分层结构

**第 4 次课（理论）— 容器管理**
- **主题**：容器生命周期；运行与停止；日志与进入；端口映射与环境变量
- **知识点**：`docker run`/`docker stop`/`docker start`/`docker restart`/`docker rm`、`docker ps`/`docker logs`/`docker exec`/`docker inspect`、`-p`端口映射、`-e`环境变量、`-d`后台运行、`--name`命名
- **项目任务**：运行 MySQL 容器并连接验证
- **互动**：编程小测验——`docker run` 参数含义
- **思政**：运维责任——容器管理是系统稳定的基础
- **考核点**：容器生命周期命令、端口映射、环境变量

**第 5 次课（实践）— 镜像与容器管理综合实践**
- **主题**：综合实践——完成 CTTS 各服务容器操作
- **任务**：拉取 MySQL/Nginx/Java 镜像，运行 MySQL 容器并初始化数据库，运行 Nginx 容器部署静态页面，容器间网络通信验证
- **互动**：项目任务复盘——容器踩坑
- **思政**：工匠精神——每个命令参数都要理解
- **考核点**：镜像与容器综合操作

#### 模块 3：Dockerfile 与镜像构建

**第 6 次课（理论）— Dockerfile 基础指令**
- **主题**：Dockerfile 概念；基础指令；构建镜像
- **知识点**：Dockerfile 语法、`FROM`/`RUN`/`COPY`/`ADD`/`WORKDIR`/`USER`、`docker build`/`docker tag`、构建上下文、`.dockerignore`
- **项目任务**：编写 CTTS 后端基础 Dockerfile
- **互动**：代码阅读——分析官方镜像的 Dockerfile
- **思政**：工程规范——Dockerfile 是镜像的源代码
- **考核点**：基础指令、构建命令

**第 7 次课（理论）— Dockerfile 进阶与多阶段构建**
- **主题**：进阶指令；CMD 与 ENTRYPOINT；多阶段构建；镜像优化
- **知识点**：`ENV`/`ARG`/`EXPOSE`/`VOLUME`/`LABEL`、`CMD` vs `ENTRYPOINT`（shell/exec 形式）、多阶段构建（减小镜像体积）、镜像层缓存优化、`.dockerignore`
- **项目任务**：用多阶段构建优化 CTTS 后端镜像
- **互动**：面试题导入——"CMD 和 ENTRYPOINT 的区别"
- **思政**：性能优化——小镜像更安全更高效
- **考核点**：CMD/ENTRYPOINT、多阶段构建、镜像优化

**第 8 次课（实践）— Dockerfile 构建实践**
- **主题**：综合实践——构建 CTTS 前后端镜像
- **任务**：编写 CTTS 后端 Dockerfile（Java 打包→运行）、前端 Dockerfile（Vue3 build→Nginx 部署），构建镜像并运行容器验证
- **互动**：项目任务复盘——Dockerfile 构建踩坑
- **思政**：质量意识——镜像构建是一次性交付物
- **考核点**：Dockerfile 编写与镜像构建

#### 模块 4：Compose 与网络存储

**第 9 次课（理论）— Docker 网络**
- **主题**：Docker 网络模型；bridge/host/none；自定义网络；容器间通信
- **知识点**：Docker 网络驱动（bridge/host/none/macvlan）、`docker network create`/`ls`/`inspect`/`connect`、容器间通过容器名通信、端口映射回顾
- **项目任务**：创建自定义网络，实现前后端容器通信
- **互动**：两人一组讲解 Docker 网络通信流程
- **思政**：网络安全——容器网络隔离
- **考核点**：网络驱动、自定义网络、容器通信

**第 10 次课（理论）— Docker 数据卷与持久化**
- **主题**：数据持久化需求；数据卷；绑定挂载；数据备份
- **知识点**：`-v`/`--mount`、数据卷（volume）vs 绑定挂载（bind mount）、`docker volume create`/`ls`/`inspect`/`rm`、数据卷共享（`--volumes-from`）、MySQL 数据持久化
- **项目任务**：MySQL 容器数据持久化配置
- **互动**：代码找错——数据未持久化导致丢失的反例
- **思政**：数据安全——持久化是数据安全的底线
- **考核点**：数据卷、绑定挂载、持久化配置

**第 11 次课（理论）— Docker Compose 多容器编排**
- **主题**：Compose 简介；docker-compose.yml；多服务编排；常用命令
- **知识点**：Docker Compose v2、`docker-compose.yml` 结构（services/networks/volumes）、`image`/`build`/`ports`/`volumes`/`depends_on`/`environment`/`networks`、`docker compose up`/`down`/`logs`/`ps`/`exec`
- **项目任务**：编写 CTTS 三服务 Compose 编排文件
- **互动**：接口设计讨论——服务依赖顺序
- **思政**：工程化——编排让部署可重复
- **考核点**：Compose 文件编写、编排命令

**第 12 次课（实践）— Docker 综合实践**
- **主题**：综合实践——CTTS 多服务 Docker 完整部署
- **任务**：编写前后端 Dockerfile、docker-compose.yml（含 MySQL+Backend+Frontend+网络+数据卷），一键启动完整应用，验证访问
- **互动**：项目演示——Docker 部署成果展示
- **思政**：完整交付——从代码到容器的全链路
- **考核点**：Docker 综合应用能力

### Kubernetes 部分（第 13-24 次课）

#### 模块 5：K8s 认知与集群搭建

**第 13 次课（理论）— Kubernetes 认知与架构**
- **主题**：K8s 简介；为什么要 K8s；K8s 架构；核心概念总览
- **知识点**：K8s 定位（容器编排）、K8s vs Docker Compose、K8s 架构（Master: API Server/etcd/scheduler/controller-manager；Node: kubelet/kube-proxy/container-runtime）、Pod/Deployment/Service 概念总览
- **项目任务**：了解 CTTS K8s 部署目标
- **互动**：课前讨论"Docker Compose 能解决所有部署问题吗"
- **思政**：自主可控——K8s 是云原生操作系统
- **考核点**：K8s 架构、核心概念

**第 14 次课（理论）— K8s 集群搭建**
- **主题**：Minikube 单机集群；kubeadm 多节点集群；kubectl 配置
- **知识点**：Minikube 安装与启动、kubeadm 初始化集群（init/join）、kubectl 安装与配置（kubeconfig）、集群验证（`kubectl get nodes`/`kubectl cluster-info`）
- **项目任务**：搭建 Minikube 单机集群
- **互动**：实操演示——学生同步搭建集群
- **思政**：实践出真知——亲手搭建才能理解架构
- **考核点**：集群搭建、kubectl 基本命令

#### 模块 6：Pod 与工作负载

**第 15 次课（理论）— Pod 与生命周期**
- **主题**：Pod 概念；Pod YAML；Pod 生命周期；kubectl 操作
- **知识点**：Pod 最小调度单元、Pod YAML 结构（apiVersion/kind/metadata/spec）、容器定义（image/ports/env/resources）、Pod 生命周期（Pending/Running/Succeeded/Failed）、`kubectl run`/`get pods`/`describe pod`/`logs`/`exec`
- **项目任务**：编写 CTTS 后端 Pod YAML 并部署
- **互动**：代码阅读——分析 Pod YAML 各字段
- **思政**：精细管理——每个资源都是声明式定义
- **考核点**：Pod YAML、Pod 生命周期、kubectl 命令

**第 16 次课（理论）— Deployment 与 ReplicaSet**
- **主题**：Deployment 概念；副本管理；滚动更新与回滚；标签与选择器
- **知识点**：Deployment vs Pod、ReplicaSet 副本控制、Deployment YAML（replicas/selector/template）、滚动更新（`kubectl set image`）、回滚（`kubectl rollout undo`）、标签与选择器（labels/selectors）、`kubectl scale`
- **项目任务**：部署 CTTS 后端 Deployment（3 副本）
- **互动**：面试题快问快答——Deployment 滚动更新原理
- **思政**：高可用——多副本是稳定性的保障
- **考核点**：Deployment YAML、副本管理、滚动更新与回滚

**第 17 次课（实践）— 工作负载管理实践**
- **主题**：综合实践——CTTS 工作负载部署
- **任务**：部署 CTTS 前后端 + MySQL 的 Deployment，配置副本数、资源限制、标签选择器，验证滚动更新与回滚
- **互动**：项目任务复盘——K8s 部署踩坑
- **思政**：运维能力——声明式部署是云原生核心
- **考核点**：Deployment 综合部署

#### 模块 7：Service 与网络

**第 18 次课（理论）— Service 服务发现与负载均衡**
- **主题**：Service 概念；ClusterIP/NodePort/LoadBalancer；服务发现；Endpoints
- **知识点**：Service 作用（稳定 IP + 负载均衡）、Service 类型（ClusterIP/NodePort/LoadBalancer/ExternalName）、Service YAML、标签选择器关联 Pod、DNS 服务发现、Endpoints
- **项目任务**：为 CTTS 各 Deployment 创建 Service
- **互动**：小组讨论——何时用 ClusterIP，何时用 NodePort
- **思政**：服务化思维——微服务间通过 Service 通信
- **考核点**：Service 类型、Service YAML、服务发现

**第 19 次课（理论）— Ingress 与外部访问**
- **主题**：Ingress 概念；Ingress Controller；路由规则；HTTPS
- **知识点**：Ingress 作用（七层路由）、Ingress Controller（Nginx Ingress/Traefik）、Ingress YAML（host/path/backend）、基于域名的虚拟主机、路径路由、TLS/HTTPS 配置
- **项目任务**：配置 CTTS Ingress 实现域名访问
- **互动**：代码阅读——分析 Ingress 路由规则
- **思政**：用户体验——统一的入口让访问更简单
- **考核点**：Ingress YAML、路由规则、HTTPS

**第 20 次课（理论）— K8s 网络进阶**
- **主题**：K8s 网络模型；DNS；NetworkPolicy 网络策略
- **知识点**：K8s 网络模型（Pod 间直接通信）、CoreDNS 域名解析（`namespace.svc.cluster.local`）、NetworkPolicy 网络隔离（入站/出站规则）、CNI 插件概念
- **项目任务**：配置 CTTS 服务间 DNS 解析与网络策略
- **互动**：面试题快问快答——K8s DNS 解析原理
- **思政**：网络安全——网络隔离是安全的基础
- **考核点**：K8s DNS、NetworkPolicy

#### 模块 8：配置存储与综合实践

**第 21 次课（理论）— ConfigMap 与 Secret 配置管理**
- **主题**：配置管理需求；ConfigMap；Secret；环境变量与文件挂载
- **知识点**：ConfigMap 概念与创建（`kubectl create configmap`/YAML）、Secret 概念与创建（base64 编码/`kubectl create secret`）、ConfigMap/Secret 挂载方式（环境变量/Volume 文件）、配置热更新
- **项目任务**：将 CTTS 数据库配置提取为 ConfigMap，密码提取为 Secret
- **互动**：代码找错——密码明文存储在 YAML 的反例
- **思政**：安全意识——敏感信息必须用 Secret
- **考核点**：ConfigMap/Secret 创建与挂载

**第 22 次课（理论）— 持久化存储（PV/PVC/StorageClass）**
- **主题**：存储需求；PersistentVolume；PersistentVolumeClaim；StorageClass；动态供给
- **知识点**：PV（集群级存储资源）、PVC（存储申请）、StorageClass（动态供给）、PV/PVC 生命周期（Available/Bound/Released）、`kubectl get pv`/`pvc`/`sc`、MySQL 数据持久化到 PV
- **项目任务**：为 CTTS MySQL 创建 PV/PVC 持久化存储
- **互动**：两人一组讲解 PV/PVC 绑定流程
- **思政**：数据安全——持久化存储是数据保障
- **考核点**：PV/PVC/StorageClass、持久化配置

**第 23 次课（实践）— 综合项目实践一：容器化应用部署**
- **主题**：综合实践——CTTS 完整 K8s 部署
- **任务**：编写 CTTS 全部 K8s 资源清单（3 个 Deployment + 3 个 Service + ConfigMap + Secret + PV/PVC + Ingress），部署到集群，验证服务访问
- **互动**：项目任务复盘——部署问题汇总
- **思政**：综合能力——从容器到集群的完整链路
- **考核点**：K8s 综合部署能力

**第 24 次课（实践）— 综合项目实践二：K8s 集群运维与项目答辩**
- **主题**：综合实践——集群运维、故障排查与项目答辩
- **任务**：模拟故障场景（Pod 崩溃/节点不可用/服务不可达），排查并修复；项目演示与答辩，提交交付物（YAML 清单 + 部署文档 + 演示）
- **互动**：项目答辩——师生共同评审
- **思政**：完整交付——能部署、能运维、能排障才是合格交付
- **考核点**：运维排障能力、项目答辩

3. 全部题目提供参考答案与解析。
4. 主观题含评分标准（按要点/分项给分）。
5. 难度分层：基础 50% / 提高 30% / 综合 20%，标注 ★/★★/★★★。
6. 贴近容器化运维岗位与就业面试。
7. 题目编号：`次课-题型-序号`，如 `01-选择-001`。

### 15.2 三个文档的关系

- **教学设计**是教师的"教案"，偏组织流程，回答"**这节课怎么教**"。
- **教学资料**是学生的"讲义/复习资料"，偏知识内容，回答"**这节课学了什么**"，包含定义、命令、完整示例。
- **题库**是测评依据，偏考核评价，回答"**这节课考什么**"。

三者相互独立又彼此呼应：教学设计引用教学资料中的知识点编号，题库题目对应教学资料中的知识点，形成"教—学—考"闭环。

### 15.3 每次课三文档统一内容规范

#### 一、`教学设计.md`（教师教案）包含：

1. 课程信息（次序 / 学时 / 理论或实践属性 / 教学主题）
2. 教学目标（知识 / 能力 / 素质）
3. 主要知识点纲要（简要列出，详细内容见同文件夹内 `教学资料.md`）
4. 项目任务或案例任务
5. 课堂互动设计（互动问题 / 组织方式 / 预期学生输出 / 教师点评要点）
6. 课程思政融入点（融入点 / 技术关联 / 引导问题 / 预期价值目标）
7. 课堂练习或随堂测验
8. 课后任务
9. 对应岗位能力或面试考点
10. 教学资料与题库索引（指向同文件夹内 `教学资料.md` 与 `题库.md`）

#### 二、`教学资料.md`（学生复习资料）包含：

1. 学习导读（本节定位、先修基础、学习目标）
2. 知识点详解（每个知识点统一结构：**定义 → 原理 → 问题/场景 → 完整示例代码/命令 → 图示 → 易错点 → 小结**）
3. 综合示例（贴近项目的完整 Dockerfile/YAML/命令案例）
4. 拓展阅读（选学内容、原理深挖）
5. 本节小结与知识结构图（思维导图 / 知识卡片）
6. 复习思考题（非题库题，开放式思考）

> **教学资料质量要求（严格执行）**：
> 1. 内容**完整详细**，有严谨的定义、原理讲解，不遗漏关键概念。
> 2. 示例代码/命令须**完整可运行**（含完整 Dockerfile / docker-compose.yml / K8s YAML / shell 命令 / 预期输出），不能只给片段。
> 3. 确保学生可以**独立操作**：提供详细的操作步骤、环境要求、命令执行顺序、预期输出、常见报错排查。
> 4. 代码/命令贴近项目实践，前后连贯。
> 5. 每个知识点后附易错点与小结。

#### 三、`题库.md`（考试系统题库）包含：

- 40 道选择题（单选/多选混合，每题 2 分）
- 20 道判断题（每题 1 分）
- 10 道填空题（每题 2 分）
- 4 道论述题/简答题（每题 5~10 分）
- 2 道程序阅读/补全题（每题 10~15 分，Dockerfile/YAML 补全）
- 2 道编程/接口设计题（每题 15~20 分，编写 Dockerfile/YAML）
- **全部题目**含：参考答案、解析、难度标注（★/★★/★★★）、所属知识点、题目编号（`XX-题型-序号`）
- **主观题**另附**评分标准**（按要点/分项给分）
